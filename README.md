# Duhuze RSVP

Event RSVP and guest management platform. Create events, send invitations, collect responses, and manage your guest list.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Database**: PostgreSQL with Neon & Drizzle ORM
- **Authentication**: Clerk
- **Email**: Resend
- **Styling**: Tailwind CSS v4
- **Background Jobs**: Inngest
- **Payments**: Pesapal, Intouch (Rwanda mobile money)
- **File Uploads**: Uploadthing
- **Hosting**: Hostinger
